# Minimap Highlight

Godot 4 editor plugin. Find matches use a contrasting orange in the script text and on the minimap. Breakpoints use the editor breakpoint color on the minimap.

While Find or Replace is open, every match is marked. Match case and whole words follow the find bar. Closing the bar or clearing the query removes the find marks. Breakpoint marks stay until the breakpoint is removed.

## Install

Copy `addons/minimap_highlight` into your project's `addons` folder. Enable **Minimap Highlight** under Project > Project Settings > Plugins.
